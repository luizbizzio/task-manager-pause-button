# Contributing to Task Manager Pause Button

Compile [`task-manager-pause-button.wh.cpp`](task-manager-pause-button.wh.cpp) as a local mod in Windhawk on Windows 11. The [README](README.md) shows the control in Task Manager.

## Review a change

Verify the Pause and Resume transitions with a changing process list. Check that reopening Task Manager and toggling the mod leave the control and update state consistent. For layout changes, try resizing the window and check the control with the scaling and language you tested.

Include the Windows build, Windhawk version, Task Manager view, and whether the failure happens on the first launch or after reopening the window. Add a screenshot if the visible control changes.
